# Hotel Booking Cancellation Analysis Dashboard

## Project Overview

This project analyzes hotel booking and cancellation trends using Microsoft Excel. The project includes data cleaning, pivot table analysis, and an interactive dashboard to derive meaningful business insights.

## Tools Used

- Microsoft Excel
- Data Cleaning
- Pivot Tables
- Pivot Charts
- Slicers
- Dashboard Design
- Data Visualization

## Project Workflow

### 1. Raw Data
Imported the original hotel booking dataset for analysis.

### 2. Data Cleaning
- Removed duplicate records
- Handled missing values
- Corrected data inconsistencies
- Prepared data for analysis

### 3. Pivot Table Analysis
Created pivot tables to analyze:
- Hotel bookings by country
- Guest type distribution
- Booking status trends
- Hotel-wise cancellations
- Average Daily Rate (ADR)

### 4. Dashboard Development
Built an interactive dashboard using:
- KPI Cards
- Pivot Charts
- Slicers
- Dynamic Filters

## Dashboard Features

### KPI Metrics
- Total Bookings
- Total Cancellations
- Cancellation Rate

### Visualizations
- Top 10 Countries by Hotel Bookings
- Booking Status vs Cancellations
- Hotel Type Distribution
- Hotel-wise Cancellation Share
- Guest Type Analysis
- Average Daily Rate (ADR) Analysis

### Interactive Filters
- Booking Year
- Booking Month

## Key Insights

- City Hotels contribute the highest number of bookings.
- Couples represent the largest guest segment.
- Cancellation rates significantly impact hotel revenue.
- Portugal (PRT) contributes the highest number of bookings.
- ADR trends vary across different months.
